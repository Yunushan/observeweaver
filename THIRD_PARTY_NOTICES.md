The repository-level 0BSD license applies only to ObserveWeaver's original
code and documentation. ObserveWeaver downloads, configures, or references
independent software. It does not relicense that software.

Operators must review the current upstream licenses and terms for:

- Prometheus and Alertmanager
- Grafana OSS
- OpenTelemetry Collector
- Graylog Open and Graylog Data Node
- OpenSearch
- MongoDB Community Server and Kubernetes operator
- PostgreSQL
- WinSW
- Ansible collections
- Kubernetes and Helm charts
- Container images, plugins, dashboards, and exporters they add

No upstream binary or chart is vendored in this repository. Source and release
URLs are recorded under `versions/`.
